## 🚀 5-Minute Quick Start

### Open 3 Terminals

**Terminal 1:**
```bash
cd contracts
npx hardhat node
```

**Terminal 2:**
```bash
cd contracts
npx hardhat compile
npx hardhat run scripts/deploy.ts --network localhost
```

**Terminal 3:**
```bash
cd socialvibe-tokenizer
npm run dev
```

### Browser: Open http://localhost:3000
